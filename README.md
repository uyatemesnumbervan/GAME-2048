# 2048 — Python Game

Классическая игра 2048, реализованная на Python с использованием библиотеки Pygame.

## О проекте

Игрок перемещает плитки на игровом поле 4×4 и объединяет одинаковые значения. Цель игры — получить плитку со значением 2048.

## Стек

* Python 3.11.5
* Pygame 2.6.1
* SDL 2.28.4

## Структура проекта

* `2048_project.py` — основной файл игры
* `README.md` — описание проекта

## Возможности

* игровое поле 4×4;
* перемещение плиток;
* объединение одинаковых плиток;
* появление новых плиток;
* подсчёт очков;
* проверка доступных ходов.

## Управление

| Клавиша | Действие |
| ------- | -------- |
| `↑`     | Вверх    |
| `↓`     | Вниз     |
| `←`     | Влево    |
| `→`     | Вправо   |

## Параметры

* Размер окна: **600 × 600 px**
* Размер игрового поля: **4 × 4**
* Целевая плитка: **2048**

## Цель проекта

Проект создан для практики Python и разработки игровой логики с использованием Pygame.

В проекте применены:

* списки и матрицы;
* функции;
* циклы и условные конструкции;
* обработка событий клавиатуры;
* игровой цикл;
* отрисовка графики;
* работа с координатами.
